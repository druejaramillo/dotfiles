# Hero lab

Require a resolvable full-page prototype. Default to **four** hero studies
unless the user specifies a count. Inspect the prototype, product facts, visual
system, and catalog evidence. Preserve the full-page draft unchanged. Load
`impeccable` and `design-inspo`.

Use separate Herdr subagents for hero studies when available, one directory per
hero; otherwise work sequentially. Every hero fills a viewport, uses an original
local asset, and is distinct in composition, crop, hierarchy, or information
treatment while remaining in the selected visual family.

Create a self-contained exploration route with a full-viewport hero frame and a
visible, accessible floating picker centered near the bottom. Add **one generic
`Hero lab` entry** to the selected family's local controls, not individual
trials to the main comparison header. Add a discreet link back to the preserved
full-page draft. The picker must be high contrast, keyboard-usable, above the
frame, within mobile safe insets, and scrollable if needed. Keep its selection,
accessible label, URL state (when used), and iframe source synchronized.

Check the actual Vite development route at desktop and mobile sizes with
`web_screenshot`. Browser-focus the picker, change a choice via keyboard, and
confirm the frame and rendered hero update. Check the production preview and
build output for the lab, draft, all heroes, and local assets. Stop before
promoting a hero.
