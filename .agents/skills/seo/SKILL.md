# Search Visibility Audit

Ask for the site or pages, priority queries, audience, and available Search
Console/analytics or AI-answer evidence. Read
`.agents/product-marketing-context.md` when present. Do not infer a trend
without baseline data.

- **Crawling, indexation, titles, content, links, rankings, performance:**
  read [traditional SEO audit](references/seo-audit/guide.md). Start with
  indexability before recommending content polish. Browser-rendered schema
  can be absent from raw HTML fetches; do not claim it is missing without a
  rendering-capable check.
- **AI Overviews, ChatGPT/Perplexity citations, AEO/GEO/LLM visibility:**
  read [AI-answer visibility](references/ai-seo/guide.md). Check actual target
  queries on requested platforms when access permits; otherwise present a
  measurement plan, not a claim about current visibility. Distinguish
  discoverability, extractability, source quality, and third-party presence.
- **Both:** assess the traditional technical foundation first, then test
  AI-answer citations for representative queries. Give one prioritized
  report with separate evidence for each channel.

The AI guide contains time-sensitive platform descriptions and numerical lift
claims. Verify them against current primary sources before repeating them as
facts; do not promise rankings or citations. Distinguish observed findings,
tool limitations, and testable recommendations. You can recommend structured
data and site architecture without installing other skills.
