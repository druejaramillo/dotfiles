# Conversion Rate Optimization

Route by the bottleneck. Use both guides only if the task spans the page and
its form. Read `.agents/product-marketing-context.md` when present, then ask
only for missing audience, traffic source, conversion goal, and baseline data.

- **Page proposition, copy, hierarchy, trust, objections, pricing, or CTAs:**
  read [page CRO](references/page-cro/guide.md). It links to detailed
  page-experiment references if needed.
- **Lead, demo, contact, application, survey, or checkout form completion:**
  read [form CRO](references/form-cro/guide.md). This guide does **not** cover
  signup/registration; for those flows, inspect the actual journey and apply
  only relevant principles rather than assuming it is a lead form.
- **Both:** first identify where visitors leave (page-to-form or within-form),
  then read the matching sections of each guide. Avoid conflicting CTAs or
  treating different measurement denominators as one conversion rate.

Ground findings in the supplied page, rendered UI, analytics, or user research.
Label suggestions as hypotheses when evidence is unavailable. Report the goal,
evidence, and constraints. Prioritize a few changes with rationale and propose
measurable tests, not promised conversion lifts. Check downstream, legal, and
sales needs before recommending that a field be removed.
