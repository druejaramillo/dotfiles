# Scholarly sources

Use available tools before assuming a particular CLI is installed. This
reference does not install alphaXiv, Feynman or a scholarly service.

For a DOI/arXiv/PMID or known paper, resolve its canonical record through the
publisher, arXiv, Crossref, OpenAlex, Semantic Scholar, PubMed or Europe PMC as
appropriate. Record title, authors, year/version, stable ID, URL and venue when
known. Distinguish preprint and peer-reviewed versions and resolve ambiguous
names by exact titles/identifiers.

For discovery, vary phrasings and periods with the available web/scholarly
tools. Use abstracts to triage, then actual text and methods/results for
consequential claims. Label abstract-only evidence. Read the PDF reference when
conclusions span pages, figures, tables or supplements.

For implementation claims, verify repository URL, license/version and relevant
paths. Running its code is a separate authorized execution task. Prefer public
sources when they suffice; do not require login or install a missing CLI just
to answer. If a compatible scholarly tool is available, follow its documented
interface and still check material claims against the underlying paper.
