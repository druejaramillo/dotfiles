# Compare

Compare the supplied sources, options or claims on common useful criteria.

1. Identify the decision and comparison set. Choose dimensions that affect it.
   Include direct, indirect or substitute options only when the decision needs
   them.
2. Read the underlying evidence for each option. Align dates, populations,
   versions, units, metrics and conditions. Mark incomparable results rather
   than forcing a winner.
3. Find the strongest case for and against each option. Label self-reported,
   independently checked, inferred and unavailable evidence.
4. Explain when each option wins, meaningful agreements/disagreements and what
   evidence would change the decision. Avoid invented weights or decorative
   numerical scores.

Use chat for a small comparison, or the requested location /
`outputs/<slug>-comparison.md` for substantive work. Include the answer,
scope/criteria, concise evidence-and-caveat matrix, decision conditions and
verification gaps. Source claims do not become independently verified merely
because they appear in the same table.
