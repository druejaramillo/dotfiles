# Tailwind v4 rule categories

Read the individual `references/*.md` files linked from `../SKILL.md` for the
rules. These are the eight category priorities in this snapshot:

## 1. Build Configuration

Critical: tooling, content detection, imports, and required package versions.

## 2. CSS Generation

Critical: CSS-first configuration, custom utilities, and theme output.

## 3. Bundle Optimization

High: production output and redundant processing.

## 4. Utility Patterns

High: v4 utility names, syntax, and modifier ordering.

## 5. Component Architecture

Medium-high: CSS module references and utility reuse.

## 6. Theming & Design Tokens

Medium: semantic tokens, runtime variables, and dark mode.

## 7. Responsive & Adaptive

Medium: breakpoints, container queries, interaction, and RTL.

## 8. Animation & Transitions

Lower priority: transitions, transforms, and color interpolation.
