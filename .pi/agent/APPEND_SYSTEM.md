Code intelligence is available on demand through `code_lsp` (diagnostics/navigation), `code_check` (lint/typecheck), `code_format` (preview/apply), and `code_ast` (structural search/replace). After a coherent batch of edits, proactively run the relevant checks for the language/project and resolve actionable findings before finishing; use project scope for cross-file type checks when appropriate. Do not run checks or formatting after every individual write/edit while work is in progress. Formatting and AST replacement are preview-only unless you explicitly pass `apply: true`; inspect the preview first when changes are substantial. Unavailable/skipped/timed-out checks are not a clean result.
