# On-demand code tools for Pi

Loaded globally from `~/.pi/agent/extensions/agent-code-tools/index.ts`. No file/turn hooks, watchers, auto-installs, or background scans. The agent chooses when to call the four tools, usually after a coherent edit batch.

| Tool | Function |
| --- | --- |
| `code_lsp` | Current saved file diagnostics, definition, references, hover, document symbols. Positions are **1-based** line and UTF-16 column. Language servers are launched lazily, reused within the session, and stopped on session shutdown. JS/TS (`vtsls` or `typescript-language-server`), Python (`basedpyright-langserver` or `pyright-langserver`), Go (`gopls`), Rust (`rust-analyzer`), Lua (`lua-language-server`), C/C++ (`clangd`), shell (`bash-language-server`), Ruby (`solargraph`), PHP (`intelephense`), CSS/HTML/JSON (`vscode-*-language-server`), YAML (`yaml-language-server`). Requires the server in project `node_modules/.bin` or PATH. Diagnostics wait up to 6 seconds for a fresh publish; timeouts are **not** clean results. |
| `code_check` | Read-only lint/type checks: JS/TS (configured Biome or ESLint; project-scope `tsc`), Python (Ruff, Pyright), Go (project-scope `go vet`), Rust (project-scope `cargo check`), shell (ShellCheck), Ruby (configured RuboCop), PHP (`php -l`), C/C++ (`clang[++] -fsyntax-only`, without project compile flags), CSS (configured Stylelint), YAML (yamllint), Markdown (markdownlint-cli2), SQL (configured SQLFluff), JSON (configured Biome). `scope: "project"` runs project checks; default is file. Missing tool/config and file-scope-only limitations are reported explicitly. No `npm run` or arbitrary config command execution. |
| `code_format` | Format one file using project-configured Biome/Prettier (JS/TS and supported web formats), installed Ruff/Black (Python), gofmt (Go), shfmt (shell), configured clang-format (C/C++), or configured StyLua (Lua). Default is preview; `apply: true` rewrites only the target file. Skips JS/TS when no formatter config is found. Formatter failures/empty output never write. |
| `code_ast` | ast-grep search over a file or directory; `$VAR`/`$$$ARGS` metavariables. Replacement is single-file only, requires `lang`, previews by default, and requires `apply: true` to write. Search results capped; narrow a directory search if it exceeds output limits. |

All paths must exist inside Pi's current working directory (symlink escapes rejected). No shell interpolation. Mutations re-read the current file within Pi's file mutation queue. Tools report skips and errors instead of presenting them as clean checks. Only the two explicitly mutating tools can change source. No workspace-wide LSP diagnostics or arbitrary LSP code actions/renames are exposed.

Dependency: local `@ast-grep/cli` in this directory (`npm install --prefix ~/.pi/agent/extensions/agent-code-tools` to restore). Linters, servers, and formatters are **not** auto-installed. To reload in an existing Pi session: `/reload`. Run smoke test with `node --experimental-transform-types ~/.pi/agent/extensions/agent-code-tools/tests/smoke.mjs` (Node 24+).
