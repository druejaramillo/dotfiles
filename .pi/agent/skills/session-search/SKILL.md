# Recall Research Sessions

Search project artifacts first when the user asks about a known saved report. For earlier conversations, use any available session-search interface, or inspect Pi's JSONL transcripts under `~/.pi/agent/sessions/` with a targeted local text search. Read only relevant matches and nearby context; sessions can contain private content and credentials. Never publish or upload whole transcripts without explicit consent. Cite session/file paths and distinguish an old conclusion from newly verified evidence. Do not assume Feynman's `~/.feynman/sessions/` is Pi's session directory.
