# Preview Research Artifacts

Confirm the artifact exists and inspect the relevant content first. Use a visible preview/rendering tool if available. If no preview integration is installed, use an available local renderer (for example pandoc when present) and report the generated path; otherwise explain the limitation and offer the plain Markdown. Do not assume `/preview` or pandoc is installed. Do not upload private or unpublished research to a public service without permission. For PDF or figure-heavy output, check that figures, tables, citations, and page breaks survive rendering before calling it ready.
