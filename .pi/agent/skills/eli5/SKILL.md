# Explain Research Simply

If a particular paper or result is named, first locate and read the relevant source with `alpha-research` or available web/PDF tools. If only a broad topic is supplied, choose a few representative sources rather than pretending there is one definitive paper.

Answer inline unless the user asks for a file. Use one-sentence summary, the central idea, how it works using one good analogy, why it matters, what to be skeptical of, and three takeaways where that structure helps. Define jargon in place. Separate what the paper actually demonstrates from conjecture or simplified intuition. Cite the sources used; do not hide limitations to make the explanation sound easy.
