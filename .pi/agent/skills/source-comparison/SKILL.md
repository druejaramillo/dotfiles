# Source Comparison

Read `../deep-research/references/evidence.md`. Define the comparison set and dimensions before making the matrix. Use matching time periods, populations, versions, units, and criteria; when they differ, mark them incomparable rather than forcing a winner. Record self-reported versus independently checked evidence. Look for direct, indirect, and substitute options if the user's decision needs them.

Search for the strongest case for and against each option. Build `outputs/<slug>-comparison.md` with: short answer; scope and criteria; a concise matrix of option/source, claim or result, evidence URL, caveat, confidence; agreements and meaningful disagreements; decision conditions ('when X wins'); unresolved evidence gaps. Avoid decorative scores or invented weights. For key quantitative comparisons check the underlying methods and quote exact dates. Proceed without preliminary plan approval unless requested.
