# Design catalog

Discovery only: no edits, files, or implementation.

Read `~/.agents/skills/design-inspo/SKILL.md`. Derive the brief from the
argument or conversation. Run `inspo overview`, select evidence-backed tag
directions, and run `inspo context --tags "..."` for each serious candidate. Use
`inspo search` only when inspecting individual references changes the
recommendation. References and prompts supply art direction, not a brand, logo,
or layout to copy.

Return **five named visual families** that differ materially. For each, provide
tags, catalog match count, representative references, a short art-direction
thesis, and best use or risk. State no-match results honestly; limited overlap
is fine when justified by the catalog and brief. Stop after the recommendation.
