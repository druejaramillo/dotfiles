# Design handoff

Use the installed `~/.agents/skills/handoff/SKILL.md` to hand the explicitly
selected next design objective to another session. Inspect the working tree,
canonical artifacts, and reported verification commands. Separate verified facts
from claims, redact sensitive values, and write the handoff in the OS temporary
directory unless the user chose another location. Report its path. Do not
publish it, start the next objective, or edit project code.
